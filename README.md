# azik-typing

コンソールで動くSKK/AZIKタイピング練習ツールです。

## インストール

```bash
pip install -e /path/to/azik-typing
```

## 使い方

```bash
azik-typing                          # 組み込みの例文を使用
azik-typing --sentences myfile.txt   # 独自の例文ファイルを使用
azik-typing --jis                    # JIS配列モード（長音符号を : にする）
```

## 画面の見方

```
今日はいい天気ですね          ← 日本語表示
KyphqiTdkidsne               ← AZIKストローク（グレー→入力済みは白）
```

- 大文字はSKKの漢字変換開始（Shift）または送り仮名開始を表します
- `;`（セミコロン）は `っ` です

## 例文ファイルの書き方

1行1文。漢字交じりの場合はタブ区切りでひらがな読みを付け、`{}`で漢字部分を囲みます。

```
# コメント行は # で始める
ひらがなだけの文
漢字交じりの文	{かんじ}の{よみ}はこう
送り仮名あり	{おお|き}な{もの}を{た|べ}る
```

- `{読み}` … 漢字・カタカナ語（最初の文字が Shift、SKKの変換開始）
- `{読み|送り仮名}` … 送り仮名あり（読みの頭と送り仮名の頭が両方 Shift）

## キーボード配列

| オプション | 長音符号（ー） | っ送り仮名トリガー | 例 |
|-----------|--------------|-----------------|-----|
| なし（US配列） | `'` | `:` (Shift+`;`) | `ko'hi'`、`Omo:ta` |
| `--jis` | `:` | `+` (Shift+`;`) | `ko:hi:`、`Omo+ta` |

JIS配列では `:` キーがシフトなしで押せ、`;` キーのシフトが `+` になるため、`--jis` を指定してください。

## 終了

`Ctrl-C` で終了。クリア数、ミスタイプ数、ミスの多いストローク Top 3 を表示します。

## AZIKストローク一覧

AZIKはSKKの拡張ローマ字入力方式です（参考: [celclow/azik-romaji-table](https://github.com/celclow/azik-romaji-table)）。

### っ・ん・長音

| 入力 | 出力 |
|------|------|
| `;` | っ |
| `q` | ん（単独） |
| `-` | ー（長音） |

### サフィックス — ん（鼻音）

キーボード配置に基づき、各母音段のかなに隣接キーを後置するとんが付きます。

| 後置キー | 対象段 | 例 |
|----------|--------|----|
| `z` / `n` | あ段 (+あん) | `kz`=かん, `sz`=さん |
| `k` | い段 (+いん) | `kk`=きん, `sk`=しん |
| `j` | う段 (+うん) | `kj`=くん, `sj`=すん |
| `d` | え段 (+えん) | `kd`=けん, `sd`=せん |
| `l` | お段 (+おん) | `kl`=こん, `sl`=そん |

### サフィックス — 長母音・二重母音

| 後置キー | 対象段 | 例 |
|----------|--------|----|
| `q` | あ段 (+あい) | `kq`=かい, `sq`=さい |
| `h` | う段 (+うう) | `kh`=くう, `sh`=すう |
| `w` | え段 (+えい) | `kw`=けい, `sw`=せい |
| `p` | お段 (+おう) | `kp`=こう, `sp`=そう |

### 拗音 + サフィックス

`ky`・`sy`・`ty`・`ry`などの拗音ベースにも同じサフィックスが使えます。

| 入力 | 出力 |
|------|------|
| `kyp` | きょう |
| `syp` | しょう |
| `ryp` | りょう |
| `kyh` | きゅう |
| `kyl` | きょん |

### 子音連続ショートカット

ローマ字として無効な子音2文字の連続が頻出語句のショートカットになります。

| 入力 | 出力 || 入力 | 出力 || 入力 | 出力 |
|------|------|-|------|------|-|------|------|
| `ht` | ひと || `kt` | こと || `mn` | もの |
| `ds` | です || `ms` | ます || `sr` | する |
| `kr` | から || `tm` | ため || `nr` | なる |
| `st` | した || `dm` | でも || `tr` | たら |
| `tt` | たち || `mt` | また || `yr` | よる |
| `km` | かも || `gt` | ごと || `gr` | がら |
| `rr` | られ || `zr` | ざる || `wr` | われ |
| `nt` | にち || `dt` | だち || `bt` | びと |
| `tb` | たび || `nb` | ねば || `wt` | わた |
