# azik-typing

コンソールで動くSKK/AZIKタイピング練習ツールです。

## インストール

```bash
pip install -e /path/to/azik-typing
```

## 使い方

```bash
azik-typing                          # 組み込みの例文を使用
azik-typing --sentences myfile.txt   # 独自の例文ファイルを使用
azik-typing --jis                    # JIS配列モード
```

## 画面の見方

```
今日は良い天気ですね
Kyp haYoITdki dsne
```

- 日本語テキスト（上段）と AZIKストローク（下段）を表示
- グレー: 未入力 / 白背景ハイライト: 次に打つ文字 / 白: 入力済み
- 大文字 = SKK の Shift（漢字変換開始・送り仮名開始）
- 変換確定スペースも含めて表示されます（例: `Hl wo` の空白）

## キーボード配列

| オプション | 長音符号（ー） | っ送り仮名トリガー | 例 |
|-----------|--------------|-----------------|-----|
| なし（US配列） | `'` (アポストロフィ) | `:` (Shift+`;`) | `ko'hi'`、`Omo:ta` |
| `--jis` | `:` (コロンキー) | `+` (Shift+`;`) | `ko:hi:`、`Omo+ta` |

JIS配列では `:` キーがシフトなしで押せ、`;` キーのシフトが `+` になります。

## 終了

`Ctrl-C` で終了。クリア数、ミスタイプ数、ミスの多いストローク Top 3 を表示します。

## AZIKストローク一覧

公式仕様: [skk-azik.el](http://openlab.ring.gr.jp/skk/skk/main/skk-azik.el)

### っ・ん・長音

| 入力 | 出力 | 備考 |
|------|------|------|
| `;` | っ | 通常 |
| `:` / `+` | っ（送り仮名） | Shift+`;`。US=`:`、JIS=`+` |
| `q` | ん（単独） | |
| `'` / `:` | ー（長音） | US=`'`、JIS=`:` |

### サフィックス — ん（鼻音）

母音段ごとに異なるキーで「ん」を付加します。
母音単体（あいうえお）の後は機能しないため q fallback になります（例: おん=`oq`）。

| 後置キー | 対象段 | 例 |
|----------|--------|----|
| `z` / `n` | あ段 | `kz`=かん, `sz`=さん |
| `k` | い段 | `kk`=きん, `sk`=しん |
| `j` | う段 | `kj`=くん, `sj`=すん |
| `d` | え段 | `kd`=けん, `td`=てん |
| `l` | お段 | `kl`=こん, `hl`=ほん |

### サフィックス — 長母音・二重母音

| 後置キー | 対象段 | 例 |
|----------|--------|----|
| `q` | あ段 (+あい) | `kq`=かい, `sq`=さい |
| `h` | う段 (+うう) | `kh`=くう, `sh`=すう |
| `w` | え段 (+えい) | `kw`=けい, `tw`=てい |
| `p` | お段 (+おう) | `kp`=こう, `tp`=とう |

### 拗音の短縮形

し行・じ行・ち行は専用プレフィックスで1打短縮できます。

| 行 | プレフィックス | 例 |
|----|-------------|-----|
| し行 | `x` | `xu`=しゅ, `xp`=しょう, `xh`=しゅう |
| じ行 | `j` | `ju`=じゅ, `jp`=じょう, `jh`=じゅう |
| ち行 | `c` | `cu`=ちゅ, `cp`=ちょう, `ch`=ちゅう |
| き行 | `ky` | `kyp`=きょう, `kyh`=きゅう |
| り行 | `ry` | `ryp`=りょう, `ryk`=りょく |

### 送り仮名の入力

SKKでは漢字の読みをShiftで始め、送り仮名の先頭でもShiftを押します。

```
書いた  → {か|い}た  → KqIta    (K=漢字開始, I=送り仮名開始)
思った  → {おも|っ}た → Omo:ta   (っ送り仮名 = Shift+;)
降った  → {ふ|っ}た  → Hu:ta    (huは fu でも可)
```

変換確定にはスペースが必要です（送り仮名なし漢字の場合）:

```
本を    → Hl woKaRite...  (Hl=ほん, スペース=変換, wo=を)
```

### 子音連続ショートカット

ローマ字として無効な子音2文字の連続が頻出語句のショートカットになります。

| 入力 | 出力 | | 入力 | 出力 | | 入力 | 出力 |
|------|------|-|------|------|-|------|------|
| `ht` | ひと | | `kt` | こと | | `mn` | もの |
| `ds` | です | | `ms` | ます | | `sr` | する |
| `kr` | から | | `tm` | ため | | `nr` | なる |
| `st` | した | | `dm` | でも | | `tr` | たら |
| `tt` | たち | | `mt` | また | | `yr` | よる |
| `km` | かも | | `gt` | ごと | | `gr` | がら |
| `rr` | られ | | `zr` | ざる | | `wr` | われ |
| `nt` | にち | | `dt` | だち | | `bt` | びと |
| `tb` | たび | | `nb` | ねば | | `wt` | わた |
| `br` | ばら | | `mr` | まる | | `dr` | である |

### カタカナ語の入力

読みを `[よみ]` で囲むと、先頭Shiftと末尾 `[`（カタカナ変換）が付きます。

```
[じむ]  → Zimu[   (ジム)
[こーひー] → Ko'hi'[  (コーヒー、US配列)
```

## 例文ファイルの書き方

1行1文。タブ区切りで読みを付け、`{}`で変換単位を囲みます。

```
# コメント行は # で始める
ひらがなだけの文
漢字交じりの文	{かんじ}の{よみ}はこう
送り仮名あり	{おお|き}な{もの}を{た|べ}る
カタカナ語	[じむ]に{かよ|っ}ています
```

| 記法 | 意味 |
|------|------|
| `{読み}` | 漢字・カタカナ語（Shift開始、変換スペース付き） |
| `{読み\|送り仮名}` | 送り仮名あり（読みの頭と送り仮名の頭が両方Shift） |
| `[読み]` | カタカナ語（Shift開始、末尾に `[` でカタカナ変換） |
